## 关键问题

- **What separates a coding agent from autocomplete?** A coding agent can inspect project state, modify multiple files, run validation, and react to tool output.
- **What matters in adoption?** Repository context, verification loops, review burden, permission boundaries, and task selection matter more than raw code generation quality.
